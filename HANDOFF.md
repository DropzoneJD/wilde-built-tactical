## Sharp edges / things to know before touching this repo

- **No backend.** Everything reads from `window.WBT` in `assets/js/data.js`. Don't hardcode
  numbers that duplicate that data.
- **One CSS file, no framework** — `assets/css/tactical.css`. Page-scoped tweaks go in a
  `<style>` block in that page's `<head>`, not a new stylesheet.
- **Drag-and-drop grid (`portal-grid.js`) is fragile-ish by design** — it transforms
  `.grid.grid-12` panel grids into GridStack at runtime, skipping KPI rows
  (`kpiRow`/`kpiStrip`/`settingsKpiRow` ids) and hidden/inactive-tab grids. If a new page
  adds a panel grid that should NOT be draggable, give it one of those skip ids or keep it
  out of `.grid.grid-12`. If it silently fails, the page is left as-is (defensive by design)
  — check the browser console for a swallowed error before assuming the feature is broken.
- **FFL dataset** (`store/assets/ffl-data.json`, ~460 KB) is generated by
  `store/tools/build_ffl_data.py` and fetched at runtime with a bundled sample-list fallback
  if the fetch fails offline.
- This mock intentionally has **no build step** — don't introduce one without discussing it
  first; the whole point (per README) is that it opens directly in a browser.
